# steam-part (SP)

> The backend component of DevlitchInput.

`sp.exe` handles the Steam-side integration for DevlitchInput and communicates with the main application through a local TCP connection.

It is managed by **DevlitchInput** and is not intended to be run standalone.

--

## Building

### 🖥️ Requirements

- SDL3@3.4.16
- ViGEmClient
- asio@1.38.2
